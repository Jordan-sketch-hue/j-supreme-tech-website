Quick Start

Live in 15 Minutes

# No installation needed — just open and edit

# 1. Download and unzip the template
# 2. Open index.html in your text editor
# 3. Find these variables at the top of styles.css:
#    --primary: #FF8C00;      ← your brand color
#    --font-heading: 'Inter'; ← your heading font
#    --font-body: 'Inter';    ← your body font

# 4. In index.html, find all [PLACEHOLDER] text and replace:
#    [YOUR BUSINESS NAME]
#    [YOUR TAGLINE]
#    [YOUR PHONE / WHATSAPP NUMBER]
#    [YOUR EMAIL]
#    [YOUR SERVICE 1, 2, 3]

# 5. Deploy to Vercel (free):
#    → vercel.com → New Project → Import Folder → Done
Formspree Contact Form SetupSign up free at formspree.io. Create a form. Copy your Form ID (looks like xpzbkwgl). In index.html, find the <form> tag and replace action="https://formspree.io/f/YOUR_ID" with your actual form ID. Submissions arrive in your email immediately — no server code needed.
