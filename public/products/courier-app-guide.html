3 Portals. One Platform.

Every role in a courier operation gets their own purpose-built interface. No one sees what they don't need — drivers get their runs, clients track their packages, admins run the business.

Client Portal

  • Schedule pickups and deliveries
  • Real-time tracking dashboard
  • Order history and receipts

Driver Dashboard

Quick Start

From Download to Running in Under an Hour

# 1. Clone and install all dependencies
git clone [your-download-url] courier-app
cd courier-app && npm install

# 2. Copy environment file
cp .env.example .env.local

# Required environment variables:
# DATABASE_URL               → Supabase connection string
# CLERK_SECRET_KEY           → Clerk dashboard → API Keys
# NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY
# PAYLOAD_SECRET             → Any random 32-char string
# STRIPE_SECRET_KEY          → Stripe dashboard → Developers
# WIPAY_API_KEY              → WiPay merchant portal
# WIPAY_ACCOUNT_NUMBER
# NEXT_PUBLIC_APP_URL        → Your domain

# 3. Run database migrations (creates all tables)
npx payload migrate

# 4. Start development server
npm run dev
# → App:  http://localhost:3000
# → CMS:  http://localhost:3000/admin

# 5. Deploy to Vercel + Railway
vercel --prod                 # Frontend
railway up                    # Payload CMS backend

Enabling WiPay (Caribbean Payments)

Set WIPAY_API_KEY and WIPAY_ACCOUNT_NUMBER in your environment. The payment selector in checkout automatically shows WiPay alongside Stripe based on detected location. No additional code changes needed.
