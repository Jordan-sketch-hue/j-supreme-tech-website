Quick Start

From Download to Live in 30 Minutes

1

Clone & Install

Extract your download, then run:

git clone [your-download-url] my-saas
cd my-saas && npm install
2

Configure Environment Variables

Copy the example file and fill in your keys (see Env Vars section below):

cp .env.example .env.local
3

Run Supabase Migrations

This creates the users, subscriptions, and profiles tables in your Supabase project:

npx supabase db push --db-url $DATABASE_URL
4

Start Development Server

npm run dev
# → http://localhost:3000
5

Deploy to Vercel

vercel --prod
# Or connect your GitHub repo in the Vercel dashboard
# Environment variables sync automatically
Stripe Webhook Local Testing Run stripe listen --forward-to localhost:3000/api/webhooks/stripe to forward webhook events during development. The webhook secret is printed in the terminal — paste it into STRIPE_WEBHOOK_SECRET in your .env.local.
