Quick Start

Up and Running in 45 Minutes

# 1. Install
git clone [your-download-url] booking-app
cd booking-app && npm install

# 2. Environment variables
cp .env.example .env.local
# NEXT_PUBLIC_SUPABASE_URL
# SUPABASE_SERVICE_ROLE_KEY
# STRIPE_SECRET_KEY
# STRIPE_WEBHOOK_SECRET
# RESEND_API_KEY
# NEXT_PUBLIC_APP_URL

# 3. Push database schema
npx supabase db push

# 4. Start
npm run dev  →  localhost:3000

Configuring Your First Service

Go to /admin/services in your running app. Click "Add Service." Fill in name, duration (minutes), price, and optional deposit. Toggle it active. The booking calendar immediately shows this service as an option for clients.

Setting Availability

Go to /admin/availability. Set your working days and hours, lunch breaks, and buffer time between appointments. Add blocked dates for holidays. The system calculates open slots automatically — no manual calendar management.

WhatsApp Booking Link Add your booking page URL to your WhatsApp auto-reply: "Hi! Book your appointment here: [your-domain]/book". Every incoming WhatsApp enquiry self-converts into a structured booking — zero back-and-forth scheduling needed.
